## How to rebuild

From the `psa-slab-scanner/` folder:

```
python3 package/build_package.py
```

It needs pandoc 3.x, Python 3 with `pypdf`, `Pillow` and `playwright` (the Python package) and Playwright's Chromium browser (on a new machine: `python3 -m playwright install chromium`), plus git for the commit hash. It stops with an error if a document, image, drawing or manifest file is missing, and checks each PDF (size, embedded fonts, no unresolved internal links) and the zip (every manifest file present, sizes and CRCs) before it replaces the old outputs.

What it does: each Markdown file is converted by pandoc with `-f gfm-tex_math_dollars` (dollar amounts are not math); images are embedded from the document's folder; links between documents in the same PDF become PDF links; links to files that are not in the PDF point to the repository. Chromium (through Playwright) prints the documents on US Letter; pypdf inserts the drawing set unchanged, adds the footers, bookmarks and contents page numbers (laid out twice so they are right). The PDF metadata date is the package date, so a rebuild from the same inputs with the same tools gives the same content.

To change the repository link, edit `REPO_URL` at the top of `build_package.py`; the date, title and status line are next to it. The documents in each PDF and their order are in `VOLUMES`.

Last built with pandoc 3.1.3, pypdf 6.17.0, Pillow 12.3.0, Chromium 141.0.7390.37; the build took 48 s.
